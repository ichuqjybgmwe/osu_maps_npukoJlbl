# MapVault — инструкция

MapVault — локальная программа-компаньон для osu!: сохраняет ваши результаты,
ведёт профиль и lifetime pp, ищет по картам в папке Songs, считает pp и подбирает
карты для фарма. Всё работает на вашем компьютере: сайт открывается в браузере
по адресу `http://localhost:47420`, данные лежат в локальной базе SQLite.

## 1. Установка

**Вариант А — установщик.** Запустите `MapVault-Setup-<версия>.exe`. Права
администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\MapVault`,
создаются ярлыки в меню «Пуск» (и на рабочем столе, если отметить).

**Вариант Б — портативная версия.** Распакуйте `MapVault-<версия>-win-x64.zip`
в любую папку и запустите `MapVault.exe`.

Node.js, npm и другие программы ставить не нужно — всё внутри `MapVault.exe`.

> Windows SmartScreen может предупредить о «неизвестном издателе», потому что exe не
> подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## 2. Запуск

Запустите `MapVault.exe`. Откроется окно консоли (это сам сервер MapVault) и браузер
со страницей программы. Чтобы выйти — закройте окно консоли или нажмите
«Выйти из MapVault» в настройках.

Повторный запуск, когда MapVault уже работает, просто откроет страницу в браузере.

## 3. Первая настройка (≈ 3 минуты)

### 3.1. Папка Songs
Обычно MapVault находит osu! сам (реестр Windows, `%LOCALAPPDATA%\osu!`, а также путь,
который сообщает Tosu). Если нет: **Настройки → «Найти osu! автоматически»** или впишите
путь к папке `Songs` вручную и нажмите **«Сканировать»**.

Первое сканирование считает звёзды и pp каждой карты: примерно 30 мс на карту
(10 000 карт ≈ 5 минут). Дальше сканируются только новые и изменённые файлы.
Прогресс виден в настройках и в левой панели.

### 3.2. Tosu — запись результатов из игры
1. Скачайте tosu: <https://github.com/tosuapp/tosu/releases> и запустите `tosu.exe`.
2. Запустите osu!. В левой панели MapVault индикатор «Tosu» станет зелёным.

После этого каждый завершённый результат автоматически сохраняется в базу, а каждая
попытка (пасс, фейл, выход, рестарт) попадает в историю. Порядок запуска не важен:
MapVault переподключается к Tosu сам.

### 3.3. osu! API — профиль, top plays, каталог карт
1. Откройте <https://osu.ppy.sh/home/account/edit#oauth> → **New OAuth Application**.
2. Название любое. **Application Callback URL**: `http://localhost:47420/api/osu/callback`
   (точный адрес показан в настройках MapVault — если вы меняли порт, используйте его).
3. Скопируйте **Client ID** и **Client Secret** в настройки MapVault и сохраните.
4. Нажмите **«Войти через osu!»** — или просто впишите свой ник (тогда используются
   только публичные данные, этого достаточно для профиля и Farm).
5. На странице **Профиль** нажмите **«Обновить из osu! API»**.

## 4. Что где

| Страница | Что делает |
|---|---|
| **Обзор** | Что сейчас играется (через Tosu), последние результаты и попытки, что осталось настроить |
| **Профиль** | pp, ранг, точность; **lifetime pp** (набрано/потеряно за всё время); top plays, recent, история попыток |
| **Карты** | Поиск по Songs: текст + фильтры `stars>=6 ar>9 bpm<200 length<3:00 played=no`, моды (с DT/HR фильтры работают по эффективным значениям), сортировка. Вкладка «Каталог osu!» — поиск новых карт на сайте |
| **Страница карты** | Параметры с модами, pp по точности, **ваши результаты на этой карте**, все попытки |
| **PP-калькулятор** | Моды, точность или точные 100/50, промахи, комбо; несколько сценариев рядом; индикатор достоверности |
| **Farm** | Анализ вашего профиля и карты, которые дадут больше всего профильных pp за минимум времени, с объяснением каждой рекомендации |

### Как считается lifetime pp
По изменениям общего pp аккаунта между синхронизациями с osu! API. Если сыграть
score, который хуже прежнего на той же карте или не попадает в топ, — профиль не
растёт, и lifetime pp тоже. Между синхронизациями показывается оценка «ожидается после
синхронизации», посчитанная через пересчёт взвешенного топа (pp × 0.95ⁱ).

### Как работает Farm
1. По вашим лучшим результатам определяется рабочий диапазон звёзд, зависимость
   точности от сложности, любимые моды и порог входа в топ.
2. Для каждой карты и набора модов прогнозируется точность, по ней rosu-pp считает
   pp, а из pp — реальный прирост профиля (с учётом весов топа).
3. Farm Score = прирост × вероятность успеха ÷ время на карту. История фейлов на карте
   понижает шанс.
4. Когда вы сыграли рекомендованную карту, прогноз сравнивается с фактом, и модель
   подстраивается под вас (блок «Обратная связь»).

## 5. Где хранятся данные

`%APPDATA%\MapVault\`:
- `mapvault.db` — база (scores, попытки, индекс карт, настройки, история профиля);
- `backups\` — ежедневные копии базы (хранятся 7 последних);
- `logs\mapvault.log` — журнал (ротация по 5 МБ);
- `osu-cache\` — скачанные .osu-файлы для карт, которых нет в Songs.

Удаление программы данные **не** удаляет. Чтобы перенести MapVault на другой компьютер,
скопируйте эту папку.

Параметры запуска: `MapVault.exe --port=47500 --no-browser --data=D:\MapVaultData --tosu=ws://127.0.0.1:24050/websocket/v2 --no-tosu`.

## 6. Устранение проблем

| Симптом | Что сделать |
|---|---|
| Браузер не открылся | Откройте вручную `http://localhost:47420`. Адрес написан в окне консоли |
| «Порт занят» | MapVault сам попробует следующие 9 портов. Или задайте порт в настройках / `--port=` |
| Tosu «нет связи» | Запущен ли `tosu.exe`? Откройте `http://127.0.0.1:24050` — должна открыться страница tosu. Если tosu на другом порту, поменяйте адрес в настройках |
| Результат не сохранился | Сохраняются только **ваши** результаты: имя игрока должно совпадать с ником профиля. Повторы чужих игр и чужие результаты из таблицы игнорируются (в журнале будет причина) |
| Карты не находятся | Проверьте путь к Songs в настройках, нажмите «Сканировать». Ошибки по отдельным файлам видны в журнале |
| osu! API: `invalid_client` | Неверные Client ID/Secret. Создайте приложение заново и вставьте значения без пробелов |
| Вход через osu! не работает | Callback URL в приложении на osu.ppy.sh должен совпадать с адресом в настройках MapVault (включая порт) |
| «Сеть недоступна» | Без интернета работает всё, кроме синхронизации профиля, каталога и скачивания карт. Сохранённые данные доступны |
| Farm пишет «мало данных» | Нужно ≥ 5 лучших результатов со звёздами: обновите профиль через API или сыграйте карты с Tosu |
| pp отличается от сайта | См. индикатор достоверности в калькуляторе: чаще всего локальная версия карты отличается от ранкнутой, или выбраны правила stable/lazer не того клиента |
| База повреждена | Закройте MapVault, переименуйте `mapvault.db`, скопируйте последнюю копию из `backups\` под именем `mapvault.db` |

Журнал работы также виден внизу страницы **Настройки**.
