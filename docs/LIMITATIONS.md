# Ограничения и известные особенности

## Внешние сервисы

**osu! API v2**
- Нужно своё OAuth-приложение (Client ID/Secret) — ключей «по умолчанию» нет.
- ppy просит не превышать ~60 запросов в минуту; MapVault ограничивает себя сам
  (токен-бакет), поэтому массовые операции (статусы 10 000 карт ≈ 200 запросов) идут
  несколько минут.
- `/users/{id}/scores/best` отдаёт максимум 200 лучших; recent — последние 24 часа и не
  больше 100 scores. Более старые результаты, сыгранные без запущенного MapVault+Tosu,
  восстановить нельзя.
- Токен приложения живёт сутки, пользовательский обновляется по refresh token. Если
  отозвать доступ на сайте, MapVault перейдёт на публичный режим.
- Ключи хранятся в локальной базе без шифрования (как в большинстве локальных утилит).

**Tosu**
- Читает память osu!; поддержка зависит от версии tosu и клиента. Формат кадров —
  `/websocket/v2` (проверено по исходникам tosu).
- pp, которые Tosu показывает на экране результатов, иногда равны 0 (не успел посчитать) —
  MapVault считает такие pp сам через rosu-pp.
- Результаты, сыгранные, пока MapVault или Tosu не запущены, сохраняются только из
  osu! API (top/recent), с их ограничениями.

## Расчёты

**rosu-pp-js 4.0.1**
- Формулы соответствуют актуальному на момент выпуска библиотеки алгоритму osu!.
  После изменений формулы со стороны ppy значения разойдутся до обновления пакета.
- Правила stable и lazer различаются (точность слайдеров и др.) — переключатель в
  настройках и калькуляторе. Для scores из API режим определяется автоматически.
- pp зависят от точной версии .osu: если локальная карта обновлена/устарела относительно
  ранкнутой, калькулятор покажет пониженную достоверность.

**Индекс карт**
- Точные звёзды хранятся для NM, HR, DT, EZ, HT. Для комбинаций (например HRDT) фильтр
  использует ближайшее значение и помечает его «≈»; калькулятор считает точно.
- Длина карты считается по началу последнего объекта (без длины финального слайдера) —
  расхождение с сайтом в пределах секунды.
- Ranked-статус локальных карт известен только после синхронизации с osu! API; без API
  Farm предупреждает, что статус не проверен.

**Farm**
- Прогноз точности — линейная модель по вашему топу, скорректированная реальными
  результатами. На нестандартных картах (техничные, «читательские», с низким AR) прогноз
  менее точен — вероятность успеха это частично учитывает через историю попыток.
- Поиск новых карт скачивает .osu (по умолчанию до 15 за запрос), чтобы считать pp
  точно, а не по звёздам.

## Платформа

- Поддерживается **osu!stable**. osu!lazer хранит карты в своей базе (realm) — его Songs
  не индексируются; результаты из lazer через Tosu и API сохраняются.
- Режимы taiko/catch/mania: сохранение результатов и pp работают (rosu-pp поддерживает
  все режимы), но Farm и фильтры AR/CS рассчитаны в первую очередь на osu!standard.
- `MapVault.exe` не подписан сертификатом — SmartScreen может предупредить при первом запуске.
- exe проверен смоук-тестом под Wine (Windows-окружение на Linux) и в CI на
  `windows-latest`. Внутри Wine не работает HTTP-клиент undici (`fetch`), поэтому синхронизация
  с osu! API под Wine недоступна; на настоящем Windows этого ограничения нет.
- MapVault работает без окна (подсистема GUI). Выход — кнопка в интерфейсе или Диспетчер задач.
  Значка в трее нет. Для отладки можно собрать консольную версию: `node scripts/build.mjs --target=win-x64 --console`.
