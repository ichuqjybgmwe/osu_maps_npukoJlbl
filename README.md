# MapVault

**MapVault** — бесплатная программа-помощник для **osu!**. Она:

- сама сохраняет каждый ваш результат из игры (и не теряет его);
- показывает ваш профиль, лучшие и последние игры, сколько pp вы набрали за всё время;
- ищет по картам, которые уже скачаны у вас в osu! (например: «все карты 6★ короче 3 минут, которые я ещё не играл»);
- считает pp: «сколько я получу за 98% с HDDT и одним промахом?»;
- подсказывает, **какие карты сыграть, чтобы быстрее поднять pp** (раздел Farm), и объясняет, почему именно они.

Всё работает **на вашем компьютере**. Программа открывается в браузере как обычный
сайт, но этот «сайт» находится у вас на компьютере, а не в интернете. Ваши данные никуда
не отправляются.

> MapVault — неофициальная программа, к ppy (создателям osu!) отношения не имеет.
> Сам MapVault в игру не вмешивается: данные из игры он получает от tosu — той же программы,
> которой пользуются стримеры для оверлеев.

## 1. Что понадобится

| Что | Обязательно? | Зачем |
|---|---|---|
| Windows 10 или 11 (64-бит) | да | MapVault сделан для Windows |
| osu! (обычная, «stable») | да | откуда берутся карты и результаты |
| [tosu](https://github.com/tosuapp/tosu/releases) | желательно | без него результаты не будут сохраняться **автоматически во время игры** |
| Аккаунт на osu.ppy.sh | желательно | чтобы загрузить ваш профиль, лучшие игры и искать новые карты |
| Браузер (Chrome, Edge, Firefox…) | да | в нём открывается программа |

Node.js, Python и прочие «программистские» штуки ставить **не нужно** — всё уже внутри.

## 2. Как скачать MapVault

### Способ 1 — со страницы релизов (самый простой)

1. Откройте страницу **[Releases](../../releases)** этого репозитория
   (на главной странице репозитория справа есть блок «Releases» — нажмите на него).
2. Откройте самый верхний (свежий) релиз.
3. Внизу релиза есть раздел **Assets** (файлы). Скачайте **один** из файлов:
   - `MapVault-Setup-0.1.0.exe` — **установщик** (рекомендуется новичкам);
   - `MapVault-0.1.0-win-x64.zip` — **портативная версия** (без установки, просто распаковать).

   Файлы `Source code (zip)` и `Source code (tar.gz)` — это исходный код для программистов,
   **их скачивать не нужно**.

> Если в Assets только «Source code» — значит, программа ещё собирается (это занимает
> около 5 минут после публикации релиза). Обновите страницу чуть позже или используйте способ 2.

### Способ 2 — из автоматической сборки (нужно войти в GitHub)

1. Войдите в свой аккаунт GitHub (бесплатная регистрация на github.com).
2. Откройте вкладку **[Actions](../../actions)** вверху страницы репозитория.
3. Нажмите на самую верхнюю строку с **зелёной галочкой** ✅ (название «Windows build»).
4. Пролистайте вниз до блока **Artifacts** и нажмите **MapVault-windows** — скачается zip-архив.
5. Распакуйте его: внутри будут установщик `MapVault-Setup-*.exe` и архив портативной версии.

## 3. Установка и первый запуск

### Если скачали установщик (`MapVault-Setup-*.exe`)

1. Запустите файл двойным щелчком.
2. Windows может показать синее окно **«Система Windows защитила ваш компьютер»**. Это
   нормально для новых программ без платной цифровой подписи. Нажмите
   **«Подробнее» → «Выполнить в любом случае»**.
3. Нажимайте «Далее». Права администратора не нужны.
4. В конце оставьте галочку «Запустить MapVault» и нажмите «Завершить».

Потом MapVault можно запускать из меню **Пуск** (или с ярлыка на рабочем столе, если вы его создали).

### Если скачали zip (портативная версия)

1. Нажмите на архив правой кнопкой → **«Извлечь всё…»** → выберите любую папку
   (например, `D:\Programs\MapVault`).
2. Запустите `MapVault.exe` из этой папки.

### Что произойдёт при запуске

- Откроется **чёрное окно** — это «двигатель» программы. **Не закрывайте его**, пока
  пользуетесь MapVault. Закрыли окно — программа выключилась (все данные сохранены).
- Через пару секунд сам откроется **браузер** со страницей MapVault.
  Если не открылся — откройте браузер и введите адрес **`http://localhost:47420`**.

Если запустить MapVault второй раз, когда он уже работает, он просто снова откроет
страницу в браузере. Ничего не сломается.

## 4. Настройка за 5 минут

Слева внизу в программе есть три индикатора: **Tosu**, **osu! API**, **Songs**.
Задача — сделать их зелёными. На странице **«Обзор»** программа сама подскажет, что
ещё не настроено.

### Шаг 1. Папка с картами (Songs)

Обычно MapVault находит osu! **сам** — индикатор «Songs» уже будет зелёным и покажет число карт.

Если нет:
1. Откройте **Настройки**.
2. Нажмите **«Найти osu! автоматически»**.
3. Если не нашлось — впишите путь к папке `Songs` вручную. Чаще всего это
   `C:\Users\ВАШЕ_ИМЯ\AppData\Local\osu!\Songs`.
   (Как найти: в osu! откройте настройки → «Open osu! folder» → там будет папка `Songs`.)
4. Нажмите **«Сканировать»**.

Первый раз MapVault изучает каждую карту: считает звёзды и pp. Это занимает примерно
**5 минут на 10 000 карт** — прогресс виден в настройках. Потом сканируются только новые карты, это быстро.

### Шаг 2. tosu — чтобы результаты сохранялись сами

**tosu** — отдельная популярная бесплатная программа, которая «подглядывает», что
происходит в osu!: какая карта, сколько точность, какой результат. MapVault берёт эти
данные у tosu.

1. Откройте <https://github.com/tosuapp/tosu/releases>.
2. У самой свежей версии в разделе **Assets** скачайте архив для Windows и распакуйте его.
3. Запустите `tosu.exe` (можно добавить в автозагрузку).
4. Запустите osu!. В MapVault индикатор **Tosu** станет зелёным.

Готово: теперь всё, что вы сыграете, попадает в MapVault автоматически. Порядок
запуска не важен — MapVault сам переподключится к tosu.

### Шаг 3. osu! API — чтобы загрузить ваш профиль

Это нужно, чтобы MapVault увидел ваш профиль на сайте: pp, ранг, лучшие игры.
osu! просит каждую программу «представиться», поэтому придётся создать себе ключ.
Это бесплатно и делается один раз.

1. Войдите на <https://osu.ppy.sh> и откройте
   **[настройки аккаунта → раздел OAuth](https://osu.ppy.sh/home/account/edit#oauth)**.
2. Нажмите **«New OAuth Application»** (новое приложение).
3. Заполните:
   - **Application Name** — любое, например `MapVault`;
   - **Application Callback URLs** — `http://localhost:47420/api/osu/callback`
     (точный адрес написан в настройках MapVault, скопируйте оттуда).
4. Нажмите **Register application**. Появятся **Client ID** (число) и **Client Secret**
   (длинная строка — кнопка «Show client secret»).
5. В MapVault откройте **Настройки → osu! API**, вставьте оба значения и нажмите
   **«Сохранить настройки»**.
6. Нажмите **«Войти через osu!»** и подтвердите на сайте osu!.
   *(Можно и не входить, а просто вписать свой ник — для профиля и Farm этого хватит.)*
7. Откройте страницу **Профиль** → **«Обновить из osu! API»**.

> ⚠️ Никому не показывайте Client Secret — это как пароль от вашего ключа.
> MapVault хранит его только у вас на компьютере.

## 5. Как этим пользоваться каждый день

1. Запустили **tosu**, **MapVault** и **osu!** (в любом порядке).
2. Играете как обычно.
3. После каждой карты внизу справа в MapVault всплывает сообщение
   **«Сохранён результат… ≈ +3.2pp к профилю»** — значит, всё записалось.
4. Хотите понять, что играть дальше, — откройте **Farm** и нажмите **«Мои карты (Songs)»**.

Профиль с сайта osu! обновляется сам каждые 15 минут, а также через минуту после
каждой вашей игры.

## 6. Что где находится в программе

### Обзор
Главная страница. Показывает, что вы играете **прямо сейчас** (pp, точность, комбо в реальном
времени), последние результаты и попытки, а также что ещё осталось настроить.

### Профиль
- ваши pp, ранг, точность, количество игр;
- **Lifetime pp** — сколько pp вы **набрали за всё время** (и сколько потеряли, например из-за
  изменений формулы pp), с графиком;
- вкладки: **Top plays** (лучшие игры), **Recent** (последние), **История попыток**
  (включая фейлы, выходы и рестарты — их нет на сайте osu!).

### Карты
Поиск по вашей папке Songs. Пишите в строку поиска название, артиста или маппера, а
можно добавить **фильтры**:

| Пишете | Что найдётся |
|---|---|
| `camellia` | карты Camellia |
| `stars>=6` | карты от 6 звёзд |
| `stars>5.5 stars<6.2` | от 5.5 до 6.2 звёзд |
| `ar>9 bpm<200` | AR выше 9 и BPM меньше 200 |
| `length<2:30` | короче двух с половиной минут |
| `played=no` | карты, которые вы ещё не играли |
| `mypp>200 acc<97` | где у вас 200+ pp, но точность ниже 97% — можно улучшить |
| `status=ranked` | только ранкнутые (после подключения osu! API) |

Кнопки **HD HR DT EZ HT FL** показывают параметры **с модами**: например, с DT вы увидите
реальный BPM (×1.5), длину и звёзды. Есть сортировка по звёздам, pp, BPM, длине, дате
добавления, вашим результатам и т.д.

Вкладка **«Каталог osu!»** ищет новые карты прямо на сайте osu! и даёт ссылки на скачивание.

### Страница карты
Щёлкните по любой карте — увидите все её параметры, **сколько pp она даёт** при 95–100%,
**все ваши результаты на ней** и все попытки (сколько раз фейлили и на каком проценте).

### PP-калькулятор
Выберите карту (поиском или по ID с сайта osu!) и заполните сценарии: моды, точность,
промахи, комбо. Можно сравнить несколько вариантов рядом — например, «NM 99%» против «HDDT 96%».
Справа вверху — **достоверность** расчёта: зелёная значит, что расчёт делается по точно той же
версии карты, что у вас в игре.

### Farm
Подбирает карты, на которых вы **быстрее всего поднимете pp**:
- **«Мои карты (Songs)»** — среди уже скачанных;
- **«Новые карты (osu! API)»** — с сайта osu!, со ссылками на скачивание.

У каждой карты — **Farm Score** (0–100, чем больше, тем выгоднее), прогноз pp и точности,
шанс успеха и **объяснение**, почему её советуют. Можно выбрать моды и ограничить длину карты.

### Настройки
Папка osu!, tosu, ключи osu! API, режим игры (osu!/taiko/catch/mania), журнал работы и кнопка
**«Выйти из MapVault»**.

## 7. Как это работает (простыми словами)

```
  osu!  ──►  tosu  ──►  MapVault  ──►  ваш браузер
                          │   ▲
          папка Songs ────┘   └──── сайт osu! (профиль, новые карты)
```

- **tosu** читает, что происходит в игре, и передаёт это MapVault.
- **MapVault** сохраняет всё в **базу данных** — один файл у вас на компьютере.
- **Папку Songs** MapVault просматривает, чтобы знать, какие карты у вас есть, и
  заранее посчитать для каждой звёзды и pp.
- С **сайта osu!** (через «osu! API») берутся ваш профиль, лучшие игры и новые карты.
- **Браузер** просто показывает всё это красиво.

### Почему не будет дубликатов
Один и тот же результат может прийти и из tosu (сразу после игры), и с сайта osu!
(при обновлении профиля). MapVault узнаёт его по «отпечатку» (карта, счёт, комбо,
попадания, моды) и хранит **один раз**.

### Как считаются pp
Тем же расчётным «движком» (**rosu-pp**), который использует tosu и многие боты osu!. Результат
почти всегда совпадает с сайтом. Если не совпадает — чаще всего у вас на компьютере другая версия
карты (её обновили), и калькулятор об этом предупредит.

### Как считается «Lifetime pp»
**Неправильно** было бы просто складывать pp всех ваших игр: если вы сыграли карту на 200pp,
но у вас уже было на ней 250pp, профиль не вырос ни на сколько. MapVault смотрит, **насколько
реально изменились pp вашего профиля** на сайте osu!, и складывает только эти изменения.

### Как Farm выбирает карты
1. Смотрит ваши лучшие игры: на каких звёздах вы обычно играете, какая у вас точность, какие моды любите.
2. Для каждой подходящей карты прогнозирует вашу точность и считает, сколько pp это даст.
3. Считает, **на сколько вырастет профиль** (а не просто pp за карту — это разные вещи, см. выше).
4. Учитывает шанс сыграть и длину карты: короткая карта с хорошим приростом лучше длинной.
5. Когда вы сыграли рекомендованную карту, сравнивает прогноз с реальностью и **подстраивается
   под вас** (блок «Обратная связь» на странице Farm).

### Где лежат мои данные
В папке `%APPDATA%\MapVault` (вставьте этот адрес в строку проводника и нажмите Enter):
- `mapvault.db` — все ваши данные;
- `backups\` — автоматические копии за последние 7 дней;
- `logs\` — журнал работы (пригодится, если что-то сломалось).

При удалении программы данные **остаются**. Чтобы перенести MapVault на другой компьютер,
скопируйте эту папку.

## 8. Частые вопросы и проблемы

**Браузер не открылся.**
Откройте его сами и введите `http://localhost:47420`. Точный адрес написан в чёрном окне MapVault.

**Windows пишет «Система Windows защитила ваш компьютер».**
Нажмите «Подробнее» → «Выполнить в любом случае». Так бывает со всеми программами без платной подписи.

**Индикатор Tosu красный / «нет связи».**
Проверьте, что запущен `tosu.exe`. Откройте в браузере `http://127.0.0.1:24050` — должна открыться
страница tosu. Если не открывается, перезапустите tosu.

**Сыграл карту, а результат не появился.**
- Работает ли tosu (индикатор зелёный)?
- MapVault сохраняет только **ваши** результаты. Повторы чужих игр и чужие результаты из таблицы
  лидеров игнорируются специально.
- Причина всегда написана в журнале: **Настройки → Журнал** (внизу страницы).

**Карт в поиске нет или мало.**
Проверьте путь к Songs в настройках и нажмите «Сканировать». Подождите, пока закончится первое сканирование.

**osu! API пишет ошибку `invalid_client`.**
Неверно скопированы Client ID или Client Secret. Скопируйте ещё раз без лишних пробелов
(или создайте новое приложение на сайте osu!).

**«Войти через osu!» не работает.**
В приложении на сайте osu! адрес Callback URL должен **в точности** совпадать с тем, что
написан в настройках MapVault.

**Нет интернета.**
Всё, что уже сохранено, работает: профиль, результаты, поиск по картам, калькулятор.
Недоступны только обновление профиля с сайта и поиск новых карт.

**Farm пишет «мало данных».**
Нужно хотя бы 5 ваших лучших результатов: обновите профиль через osu! API или сыграйте
несколько карт с запущенным tosu.

**pp не совпадает с сайтом.**
Посмотрите на «достоверность» в калькуляторе. Обычно причина — другая версия карты у вас в Songs.
Ещё проверьте, что в настройках выбраны правила **osu!stable** (если вы играете в обычную osu!).

**Я играю в osu!lazer.**
Результаты из lazer через tosu и сайт osu! сохраняются, но поиск по картам работает только с
папкой Songs обычной osu! (lazer хранит карты по-другому).

**Как обновить MapVault?**
Скачайте новую версию и установите поверх старой (или замените `MapVault.exe`). Данные сохранятся.

**Как удалить?**
Пуск → Параметры → Приложения → MapVault → Удалить. Данные в `%APPDATA%\MapVault` удалите
вручную, если они больше не нужны.

**Ничего не помогло.**
Откройте `%APPDATA%\MapVault\logs\mapvault.log` и создайте [Issue](../../issues), приложив
последние строки журнала.

Более подробная инструкция: [docs/INSTALL.md](docs/INSTALL.md) · Известные ограничения:
[docs/LIMITATIONS.md](docs/LIMITATIONS.md).

## 9. Для разработчиков

Нужен Node.js **22.13+** (для сборки exe — ровно 22.22.0, как в CI).

```bash
npm install
npm start                 # http://localhost:47420
npm test                  # 32 теста: модульные, данные, интеграционные
npm run build:win         # dist/MapVault-<версия>-win-x64/MapVault.exe (собирается и на Linux)
node scripts/smoke-test.mjs --exe=dist/MapVault-0.1.0-win-x64/MapVault.exe
node scripts/fake-tosu.mjs --osu="путь/к/карте.osu"   # эмулятор tosu для проверки без игры
```

- Установщик: `iscc installer\mapvault.iss` (Inno Setup 6) после `npm run build:win`.
- GitHub Actions (`.github/workflows/windows-release.yml`) на каждом пуше прогоняет тесты, собирает
  exe, проверяет его смоук-тестом на Windows и собирает установщик.
- **Как выпустить релиз:** Releases → «Draft a new release» → придумайте тег (любой, например `v0.1.1`)
  → «Publish release». Через ~5 минут CI сам прикрепит к релизу установщик и zip.
  Чтобы дозагрузить файлы в уже существующий релиз: Actions → «Windows build» → «Run workflow»
  → в поле «Тег релиза» впишите тег этого релиза.
- Стек: Node.js 22, встроенный SQLite, интерфейс на чистом JS, расчёт pp — rosu-pp (WASM),
  сборка в один exe — Node SEA. Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
