# MapVault

Локальная программа-компаньон для **osu!**: надёжное сохранение ваших scores,
профиль и честный lifetime pp, мощный поиск по картам в Songs, PP-калькулятор на
проверенной реализации и Farm, который подбирает карты для роста pp и объясняет почему.

Работает на вашем компьютере: `MapVault.exe` поднимает локальный сайт
`http://localhost:47420` и открывает его в браузере. Данные — в SQLite
(`%APPDATA%\MapVault`), без облака.

## Возможности

- **Tosu**: живые данные игры; каждая попытка (пасс/фейл/выход/рестарт) и каждый
  завершённый результат сохраняются автоматически, без дубликатов.
- **osu! API v2**: профиль, top/recent plays, снимки pp и ранга, вход через osu! (OAuth)
  или публичный режим по нику; ranked-статусы локальных карт.
- **Lifetime pp**: по реальным изменениям pp аккаунта, а не суммой pp каждого score.
- **Карты**: индекс папки Songs (звёзды NM/HR/DT/EZ/HT, pp 95/98/100%), полнотекстовый
  поиск, фильтры `stars>=6 ar>9 bpm<200 length<3:00 played=no …`, моды пересчитывают
  эффективные AR/OD/BPM/длину, сортировка по 16 полям; каталог osu! с ссылками на скачивание.
- **Страница карты**: параметры с модами, pp-таблица, ваши результаты и попытки.
- **PP-калькулятор**: rosu-pp, моды, точность или точные 100/50, промахи, комбо,
  сравнение сценариев, индикатор достоверности.
- **Farm**: анализ профиля → прогноз точности → точный pp → прирост профиля ×
  вероятность ÷ время; рекомендации по модам; обратная связь по реальным результатам.
- Работает без интернета (кроме синхронизации) и без Tosu (интерфейс не ломается).

## Быстрый старт (пользователю)

Скачайте `MapVault-Setup-*.exe` или `MapVault-*-win-x64.zip` из артефактов сборки /
релизов и запустите. Подробно: **[docs/INSTALL.md](docs/INSTALL.md)** — установка,
настройка Tosu и osu! API, устранение проблем.

## Разработка

Нужен Node.js **22.13+** (сборка exe — ровно той версии, что в CI: 22.22.0).

```bash
npm install
npm start                 # http://localhost:47420 (данные в %APPDATA%\MapVault или ~/.local/share/mapvault)
npm test                  # 32 теста: модульные, данные, интеграционные
npm run build:win         # dist/MapVault-<версия>-win-x64/MapVault.exe (можно на Linux)
node scripts/smoke-test.mjs --exe=dist/MapVault-0.1.0-win-x64/MapVault.exe
node scripts/fake-tosu.mjs --osu="путь/к/карте.osu"   # эмулятор Tosu
```

Установщик: `iscc installer\mapvault.iss` (Inno Setup 6) после `npm run build:win`.
GitHub Actions (`.github/workflows/windows-release.yml`) на каждом пуше гоняет тесты,
собирает exe, проверяет его смоук-тестом на Windows и собирает установщик; тег `v*`
публикует релиз.

Документация: [архитектура и причины выбора](docs/ARCHITECTURE.md) ·
[ограничения API и библиотек](docs/LIMITATIONS.md).
